# ACORN EMPIRE — GitHub Pages 배포

## 배포 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `game.js`, `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/ (root)`를 선택한 뒤 Save를 누릅니다.
5. 잠시 후 표시되는 `https://사용자이름.github.io/저장소이름/` 주소에서 플레이할 수 있습니다.

## 포함 기능
- 클릭 수확, 황금 도토리, 자동 생산 일꾼 3종
- 코인 업그레이드, 레벨/경험치, 트로피 등급
- 업적, 일일 출석 보상, 간단한 점프 미니게임
- 브라우저 자동 저장 및 최대 8시간 오프라인 수익
- 반응형 PC/모바일 UI, 사운드/표시 설정

## 저장 및 온라인 기능 안내
현재 버전은 `localStorage`를 사용해 **현재 브라우저와 기기 안에** 진행 상황을 저장합니다. 따라서 다른 기기와 진행 상황이 자동으로 동기화되지 않으며, 명예의 전당도 데모 기록을 포함한 로컬 표시입니다. 실제 여러 이용자의 계정·실시간 온라인 랭킹을 제공하려면 별도의 백엔드와 데이터베이스, 인증 기능을 연결해야 합니다.
